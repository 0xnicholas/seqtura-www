# 首页视觉样张 v2：Laravel 方向

一次性的视觉探索，不是生产代码。要回答的问题：

> Seqtura 官网首页能否用 laravel.com 当前的视觉语言——白纸底、轻字重大标题、1px 制图、等距能力栈、白色代码面板——承载定位、方法论、架构和唯一主转化？

这版是对上一版（深色终端 + 青色发光卡片）的推倒重做。上一版没有抓住 laravel.com 的实际气质，已废弃。

## 这版对应的 Laravel 视觉规则

| laravel.com 的做法 | 这版的落法 |
|---|---|
| 近纯白画布、`#171717` 正文、`#E5E5E5` 发丝线 | 同一套底色与线色；24px 网格只做纸纹 |
| 60–72px 轻字重大标题 | H1 68px / H2 60px / 字重 400；中文行高 1.06–1.08 |
| 1280px 栅格、80px 边距、1px 分隔带 | 1440 视口下 1280 内容宽 + 80px 边距 |
| 栅格交点 7×7px 定位刻度 | 每个内容区块与 proof strip 的交点都有 7px 刻度 |
| 等距产品插图承担结构解释 | 5 层能力栈 + 3 条控制面的等距图；节点：任务进入 / 工具调用 / HITL gate |
| 代码面板作为产品证据 | 方法论区用白色 `delivery.yml` 面板，8 阶段 + 3 个门禁 |
| 巨大页脚字标 | 页脚 `Seqtura` 轻字重字标，颜色压到近背景 |
| 动效克制，只做进场与状态确认 | 只有 hover 与 600ms 入场；严格响应 `prefers-reduced-motion` |

不能挪用、这版也没有用的：Laravel 字标与 L 图形、`#F53003`、产品线色、Artisan / 社区语汇、Laracon 照片。

## 强调色

按 map 的约束，强调色用深青 `#0E7490`，而不是 Laravel 红。等距图用青 / 靛 / 琥珀区分层级。

这是这版与 laravel.com 最大的差异。如果 owner 想要更接近原站的暖红 CTA，需要先放宽 map 里「不挪用 Laravel 红色」的约束——这是一个品牌决定，不是样式微调。

## 中文排版结论（本版实测）

- **标题**：400 字重在 60–68px 可行，气质接近 Laravel；关键是字号足够大、行高 1.06–1.08、字距 -0.01～-0.018em。不要用 Laravel 的 -5% 字距，CJK 会顶字。
- **小标题**：28px 以下改用 500；400 在 20–27px 会发虚。
- **正文**：16px / 1.7；移动端 15px / 1.75。行长控制在 28–36 个汉字。
- **等宽**：只给 Latin、数字、代码；中文不进等宽。代码面板在移动端可横向滚动，桌面端不溢出。
- **字体栈**：macOS 走 SF Pro / PingFang SC；Windows 会回退到 Microsoft YaHei，行高可能需要 +0.05 复核。
- **混排**：中文与 Latin 之间保留空格；标点用全角。`text-wrap: pretty` 用于段落，减少「材料」「阶段」这类词被拆到两行。
- **页面宽度**：1440 / 1024 / 768 / 390 / 320 均无横向溢出（代码面板内部除外）。

## 推荐

保留这一版的结构作为首版方向：

1. 白底 Hero + 等距能力栈，先把「5 层 + 3 控制面」讲清楚；
2. 方法论区用白色代码面板做产品证据，而不是再放一张插图；
3. 架构区用 1px 平面图 + 三条控制面，和 Hero 的等距图形成「一张图 / 一张表」的互补；
4. 深色只保留一条 trace band，制造节奏，不压阅读；
5. 页脚巨大字标收尾。

理由：它最接近 laravel.com 当前的视觉语法，同时能装下 Seqtura 两个最重的内容区块；深色带是局部强调，不会把整站拖回「深色科技风」。

## 待 owner 决定

- **强调色**：继续用深青，还是允许更接近 laravel.com 的暖红/橙 CTA？
- **是否继续做结构变体**：上一轮 A/B/C 的主题变体已停；如果这条方向成立，可以再做两版结构差异（居中 Hero / 代码面板主视觉），而不是三套换色。
- **页脚巨大字标**：保留，还是换成更克制的页脚？
