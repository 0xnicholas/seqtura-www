05 · SPACING TRIM

标点挤压：text-spacing-trim

窄栏迫使全宽标点落到行首/行尾/相邻。左 = normal（挤压），右 = space-all（不挤压）。 仅 Chrome/Edge 123+；且依赖字体 halt/chws 特性，苹方/雅黑是否内建未验证——本页即测试。

08 · BOUNDARIES

边界与未验证项

  • Windows 雅黑未真机验证：雅黑只有 Regular/Bold，中文标题 500 会落 Bold（更重）；若观感不可接受，退路 = 中文标题保持 400、层级让位给尺度（#27 方案 c 的既定退路）。
  • text-autospace 版本门槛：Chrome/Edge 140+、Safari 18.4+、Firefox 145+ 才生效；旧浏览器静默无自动间距（优雅降级）。本页 badge 显示当前浏览器支持实况。
  • text-spacing-trim：仅 Chrome/Edge 123+；且依赖字体 halt/chws 特性，苹方/雅黑是否内建以本页实测为准。
  • 手写空格存量：src/data 现有 276 处手写「盘古之白」；接受 autospace 新默认则文案需一轮清理（规格阶段立项）。
  • latin-ext 未加载：本页只挂 latin 子集（30,092B）；若未来出现拉丁扩展字符（如德法语），latin-ext 另加 10.6KB。
  • size-adjust 标定值分平台：本页在本机（macOS）实时标定 Helvetica Neue；Windows 需对 Arial/Segoe UI 另跑一次，规格应给两组值。
  • 颜色：本页红色用 #28 锁定的 laravel 系（#FF2D20 / #cd2318 / #aa1b12），与生产现状（#f53003 系）不同，属预期。
  • mono 栈不变：kicker / mono-label 维持系统等宽栈（CJK 逐字回退系统字体），mono webfont 是预算内预留的未来项，本页不验证。
