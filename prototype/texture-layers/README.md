# 首页「第二图层」质感原型（issue #31）

一次性原型，不是生产代码。要回答的问题：

> 在已锁定的色彩（#28）与图形语言（#29 等距栈延展）下，为 hero 与关键区块加哪些质感层（渐变 / 光晕 / 网格底纹 / 纸纹）？逐区块给出「加 / 不加」的对比，并标注每层的性能代价。

与色彩、图形语言两轮原型不同：本原型直接挂在**真实首页**上（sub-shape A），所有层都是纯 CSS，用 dev-only 面板逐层开关，立即可见「加 / 不加」。

## 决议（owner 拍板，2026-11-17）

**不新增任何质感层。** 图纸网格否决（hero / 方法论 / 收尾 CTA 均不加）；纸纹否决（Linear 暗室氛围的借用，不服务制图语言，且是唯一带性能注脚的候选）；现状 5 处红色光晕全留——质感维度收敛为「光晕单材质」，性能预算零变化。下方候选层与截图留档备查。

## 打开

```bash
pnpm dev
# http://localhost:4321/   → 默认「全开」（完整提案）
```

底部黑色 `PROTO` 面板按区块列出全部候选层，点击即切换（不重载，URL 同步可分享）：

- `?tex=none` —— 全关（裸页对照，含移除现状 5 处光晕）
- `?tex=grid-hero,grain` —— 只开列出的层
- 无参数 —— 全开
- 键盘 `b`：在当前组合与「全关」之间快速往返（A/B 用）
- `?capture=1`：隐藏面板（截图用）；「性能」按钮展开逐层性能代价

## 候选层与性能代价（Lighthouse 视角）

| 层 | 位置 | 实现 | 性能代价 |
|---|---|---|---|
| 图纸网格 | hero / 方法论 / 收尾 CTA（仅 ≥1024px） | 两条 `linear-gradient` 1px 网格线（ink 4.5%，80px 格）+ 一条同色遮罩渐变压边 | 0 请求、0 JS、paint-only，无 layout/CLS；FCP/LCP/TBT 无感 |
| 红色光晕 | hero 插画后 12% · 方法论代码面板 13% · 架构区底 10% + trace 卡 16% · CTA 14% | 现状已有的 5 处 `radial-gradient`，本原型只做「去 / 留」开关 | 0 请求、paint-only；去留对预算均无实质影响 |
| 纸纹噪点 | 全局 fixed 覆层 | inline SVG `feTurbulence` data-URI（≈0.6KB，随 CSS 下载，无额外请求），有效透明度约 2% | 1 个合成层（≈5MB GPU 纹理 @1440×900）；Lighthouse 分数无直接影响；低端机滚动重绘建议真机抽查 |

面板与本脚本仅 dev 渲染，不进生产构建；原型 CSS 随生产打包但全部以 `body.tex-*` 类名为门，生产默认不生效。

设计细节：

- 网格 80px 格 = 本站 `--gutter` 节奏；≥1440 视口下与 1280 容器精确对齐（16 格整）。
- hero 遮罩以插画为锚（60% 44% 径向），文字区保持干净；CTA 遮罩反过来——文字区实心、网格向四周浮出。
- 方法论区块本身已有大量横 hairline（清单行、组卡栅格），网格是否与此打架是本原型要回答的问题之一。
- 纸纹强度 = `.tex-grain-overlay` 的 `opacity` 一个数字（当前 0.045），觉得太弱/太强直接调。

## 与「单一材质层约束」的张力（请 owner 判断时留意）

#26 对标结论：Laravel / Linear / Stripe 每家只选一个材质层做品牌载体。本站现状已带 5 处红色光晕；本提案全开 = 光晕 + 网格 + 纸纹三套质感并存，可能越界。面板的用法就是找到那条线：逐区块关掉「没挣到自己位置」的层。

## 边界

- 只看质感层：不动版式、字号、间距、动效；hero 主图维持现状（#29）。
- 网格仅桌面端渲染（沿用 Laravel 光晕的 md+ 守卫惯例；移动端 hero 插画本身隐藏，网格失去服务对象）。
- 纸纹为全视口覆层以忠实还原 Linear 手法；若采用，规格阶段再定是否收窄到特定区块或加断点守卫。
- 架构 bento 未候选网格：卡片栅格已是最密区块，密度纪律（#29）下不再加底纹。
