品牌红微调候选：红色系与中性色阶

要回答的问题：品牌红在红色系内微调（动色相/明度，不换色系），选哪一组？每组给出主红、深色变体（dark / hover）、faded / wash 背景色，并与 laravel 品牌红 #FF2D20 并排对比。

怎么读：每组的左侧是候选，右侧是同一结构的 laravel 对照。中性色阶（canvas / paper / ink / muted / line）五组完全一致，只有红色在变。第一个「校准组」是现状 #f53003 vs laravel——它们只差 ΔE00 4.12，这就是要微调的原因。

ΔE00（CIEDE2000 色差） <2 几乎不可辨 2–5 并置可辨 5–10 明显差异 >10 不同的颜色印象
校准组 · 现状 vs laravel A · 沉稳朱红 B · 绯红 C · 砖红陶土 边界与备注

色板总览

white-on-主红 = 白字直接压在主红上的对比度（WCAG AA 普通文本需 ≥4.5）。laravel 行的 dark / hover 为按本站同一梯度规则派生的参考值（laravel.com 未公开完整梯度）。

边界与备注

  • 三组候选的主红都过 WCAG AA（白字 ≥4.5）；现状 #f53003 为 3.96 未过——选定任一候选后，规格阶段可考虑「按钮直接用主红、hover 用 dark」的简化映射。
  • 性能预算影响：零。纯色值 token 替换，不新增字体、图片或脚本。
  • faded / wash 按各自主红色相等亮度（OKLCH L=0.935 / 0.982）生成，三组间观感差异极小；选中性色文字其上对比度均 ≥13:1。
  • kicker / text-link 等小字红沿用 red-dark 槽位：A #ac1c01 7.19:1、B #a30d2b 7.93:1、C #873216 8.41:1，均过 AA。
  • 本页只做颜色判断：版式、字号、间距沿用现状（较窄栏宽下 hero 为生产环境的 ≤1023px 断点形态），不评估其它设计变化。
  • 验收方式：肉眼选定一组，或给方向性反馈（更冷/更暖、再深/再浅、饱和再降等）后再迭代一轮。
